# Órbita Spanish

A Spanish learning app that shows how every word sounds in English letters (hola → OH-lah), with the stressed beat in capitals.

- 10 units, 30 lessons, 82 words and phrases
- Pronunciation questions built from the mistakes English speakers make, each with the rule behind it
- A sound-it-out tool for any Spanish word you type
- Every answer saved on the device for review, with backup and restore
- Works with no connection once installed

## Install it on a phone

1. Open the site in Safari (iPhone) or Chrome (Android).
2. iPhone: tap Share, then Add to Home Screen. Android: tap the menu, then Install app.
3. Open Órbita from the home screen. From then on it runs offline.

## Files

- `index.html`: the whole app (layout, lessons, pronunciation engine)
- `sw.js`: offline cache
- `manifest.webmanifest`, `icons/`: home-screen install
- `fonts/`: Unbounded, Hanken Grotesk and Martian Mono, each under the SIL Open Font License

Progress stays in the browser on each device. Nothing is sent to a server.
